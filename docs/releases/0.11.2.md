# ZeroSound 0.11.2

- Uses the full available playout budget for packet reordering instead of declaring audio lost
  after a fixed 20 ms timeout.
- Absorbs ordinary Wi-Fi latency bursts up to the real scheduling deadline while preserving the
  shared room presentation timeline.
- Applies the same deadline-driven policy during playback startup, preventing a reordered first
  packet from producing an avoidable glitch.
- Allows a bounded window of concurrent UDP submissions per receiver instead of serializing the
  audio stream behind completion callbacks and accidentally dropping packets locally.
- Reports concealed audio as duration rather than packet count and distinguishes packets that
  arrived after their playback deadline.
- Marks playback degraded only when concealment becomes audibly significant, while keeping minor
  handled network imperfections as technical telemetry.
- Adds deterministic regression tests for 200 ms burst jitter, true packet loss, late arrival,
  continuous concealment, rolling telemetry, compatibility, and room-health behavior.
