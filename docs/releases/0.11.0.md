# ZeroSound 0.11.0

- Replaces shared UDP room traffic with ordered TCP control and a dedicated authenticated UDP audio
  and clock plane.
- Makes joins explicit and bounded: partial joins clean up automatically and unsuccessful attempts
  return to discovery within five seconds.
- Continuously reconciles every speaker against current packet room timestamps and the latest room
  clock, correcting hardware drift during playback instead of relying on the original anchor.
- Uses bounded per-receiver audio sends so a slow Mac cannot create growing latency or stall another
  speaker.
- Detects a silent or failed UDP path and replaces it through the existing authenticated TCP session
  without leaving or rejoining the room.
- Keeps live audio isolated from unrelated members joining or leaving.
- Recovers coordinator handoff through a fenced new term, survivor reconnect, clock relock, and fresh
  stream generation.
- Expands diagnostics with control/audio transport state, join stage, before-send drops, clock skew,
  room-phase error, playback correction, and the last automatic recovery reason.
- Adds deterministic fault simulations and real TCP/UDP integration coverage for rooms of up to eight
  Macs.
