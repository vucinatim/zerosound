# ZeroSound 0.11.1

- Makes room health consequence-based: handled packet loss and reordering remain technical
  telemetry instead of producing false warnings.
- Introduces clear Excellent, Stabilizing, Degraded, and Action needed states for current playback
  quality, automatic recovery, and failures that genuinely require intervention.
- Prevents the health badge from oscillating while synchronization measurements settle or an audio
  path recovers.
- Starts fresh playback telemetry for every stream generation and clears obsolete clock metrics
  when coordinator ownership changes.
- Publishes empty renderer telemetry after playback stops, so an idle or recovered room cannot
  inherit missing-packet, underrun, resynchronization, or queue statistics from an earlier stream.
- Preserves recovered timeouts as historical incidents without allowing them to degrade current room
  health.
- Adds deterministic regression coverage for concealed loss, recovery, transport replacement,
  blocking failures, telemetry epochs, and health-state stabilization.
