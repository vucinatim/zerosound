# ZeroSound diagnostics system

## Goal

The room-health badge describes the current user experience and whether a person must act. It is
not a summary of raw network counters. Packet loss, packet reordering, clock correction, and an
automatic resynchronization are normal inputs to a resilient real-time audio system when they are
successfully absorbed.

## Boundaries

The diagnostics system has three deliberately separate layers:

1. **Telemetry** records facts such as missing packets, jitter-buffer depth, underruns, phase error,
   clock fit, transport state, and capture statistics. These values remain available in technical
   diagnostics and must not directly become UI severity.
2. **Assessment policy** converts the current room phase and observable playback consequences into
   a typed `RoomHealthAssessment`. The policy is pure and deterministic so every rule is testable.
3. **Presentation stability** prevents rapid badge oscillation. Worsening and active recovery are
   shown immediately; healthy live playback must be observed consistently before returning to
   Excellent. An idle room becomes ready immediately.

## User-facing states

- **Excellent**: the room is idle and ready, or live playback is synchronized and stable.
- **Stabilizing**: joining, preparing audio, measuring phase, replacing an audio path, or completing
  an automatic playback recovery.
- **Degraded**: a transport is unavailable, repeated underruns exceed successful recoveries, the
  playback buffer collapses, or synchronization has a sustained large phase error.
- **Action needed**: an explicit blocking failure cannot be recovered without intervention, such as
  unavailable system-audio capture or a failed room listener.

Missing or reordered packets alone never change the headline state. Their user-visible consequence,
if any, does.

## Lifecycle invariants

- Every stream generation starts with empty playback telemetry and audio levels.
- Stopping the renderer publishes empty telemetry after its internal reset.
- Changing coordinator clears the old coordinator clock fit.
- Leaving a room or starting a new diagnostics session clears all session metrics and incidents.
- A successful coordinator recovery may retain the triggering timeout as **Last incident**, but that
  historical fact does not affect current room health.
- Idle health never evaluates playback counters from an earlier stream.

## Verification

Regression coverage must preserve these scenarios:

- large amounts of concealed loss with stable phase remain Excellent;
- a handled underrun/resynchronization is Stabilizing, not Action needed;
- repeated unhandled underruns or sustained phase error are Degraded;
- automatic audio-path replacement is Stabilizing;
- a blocking capture/listener failure is Action needed;
- coordinator recovery and stream replacement begin fresh telemetry epochs;
- live recovery requires consecutive healthy observations before the badge returns to Excellent.
